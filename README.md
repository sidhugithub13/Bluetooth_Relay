# Bluetooth_Relay

The objective to control an LED using a relay switch and bluetooth

**Hardware Requirements:**

1x Breadboard,
1x Arduino Uno, 
1x LED,
1x 300 ohm resistor, 
1x 5V or 6V relay,
Jumper Wires
